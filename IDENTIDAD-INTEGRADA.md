# Identidad proporcionada por el usuario

Se integra `Logotipo AI Company en violeta.png` como recurso oficial proporcionado para esta revisión. El archivo original se copia sin modificar a `assets/identity/logo-official.png`. Su hash, autorización y ventanas de presentación están registrados en `scripts/content/brand-status.json`.

Encabezado y footer comparten el mismo logotipo en las 225 páginas. El footer utiliza una base blanca para conservar el texto original sobre fondo oscuro. No se recolorea ni se traza el símbolo.

El favicon SVG incrusta el PNG original y usa una ventana cuadrada que muestra únicamente el símbolo. Los PNG de 16, 32, 96, 180 y 512 px se renderizan desde ese SVG; el ICO contiene 16 y 32 px. El original permanece intacto. El símbolo de 512 px queda disponible como recurso reutilizable.

El recurso raster ya está disponible: no debe seguir anunciándose como pendiente. Un archivo vectorial independiente no fue proporcionado y puede incorporarse más adelante si se necesita para impresión, sin sustituir este recurso por un trazado aproximado.

Se conservan contenidos, enlaces, metadatos, sitemap, robots y clasificaciones de indexación. No se cambian datos legales. La revisión legal/NIT y la autorización de publicación definitiva siguen pendientes. `reviewOnly: true` mantiene el bloqueo de release aunque ahora exista el logotipo. La demo conserva noindex y no envía formularios.
